# Werewolf Audio Bundle

This bundle contains the current audio spec, implementation guide, manifest, status CSV, and production checklist.

Important: the approved 23 narration clips were generated through the connected voice service, but their audio binaries could not be copied into this sandbox ZIP. Their generated preview/download references are stored in `audio_manifest.json` and `audio_generation_status.csv`. The narration folder is therefore intentionally empty except for `.gitkeep`.

Do not treat missing binary files as generated local assets.
